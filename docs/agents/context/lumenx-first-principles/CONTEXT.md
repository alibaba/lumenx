# LumenX 创作领域词汇

术语核对：2026-10-09。只记录领域含义，不维护方案与进度；材料入口见 [README](README.md)，当前执行状态见 [台账](EXECUTION-STATUS.md)。

## Language

**本地创作**：一位创作者在承载其 LumenX 项目的本机上开展创作，可以通过不同窗口或入口操作同一创作环境。
_Avoid_：离线创作（本地创作仍可调用云端模型）

**远程创作**：同一位创作者通过网络，从其他设备访问自己部署的 LumenX 创作环境并操作项目。
_Avoid_：云端生成（模型在哪里执行与创作者如何访问项目是不同概念）

**协作创作**：多位创作者共同操作一个共享项目，可能同时对其作出修改。
_Avoid_：工作室使用（工作室的成员各自使用独立项目，并不自然构成共享项目协作）

**正式项目状态**：项目所属的 LumenX 创作环境确认保存的创作内容、素材关系与任务记录，是不同操作入口判断项目现状的共同依据。
_Avoid_：界面当前显示（其中可能包含草稿与尚未确认保存的修改）

**创作环境**：承载并管理项目、素材与任务的一处 LumenX 创作空间，可以位于本机或创作者选择的远端。
_Avoid_：操作入口（同一环境可以从不同入口访问）

**操作入口**：创作者进入 LumenX 开展操作的界面形式，包括浏览器与桌面应用；入口本身不决定项目归属。
_Avoid_：本地版、云端版（将入口形式与创作环境的位置混为一谈）

**可编辑项目**：保留创作结构、素材关系及相关生成成果，可供继续修改和创作的项目内容。
_Avoid_：成片（播放或交付用的视频结果，不等于可继续编辑的项目）

**项目副本**：由既有可编辑项目复制得到的独立项目；原项目与副本分别继续创作，后续修改互不影响、不自动同步。
_Avoid_：缓存、自动同步镜像（副本具有独立的创作过程）

**功能入口**：创作者在 Studio 生产流程、Atelier 画布或通过 Agent 发起具体创作操作的方式。
_Avoid_：操作入口（浏览器与桌面应用属于访问形式，是另一个维度）

**模型能力**：某个具体模型能够处理的创作输入与生成方式的范围。
_Avoid_：入口能力（模型具备某项能力，不代表每个功能入口都已开放）

**入口能力**：某个功能入口明确提供给创作者使用的模型能力范围，可以是模型能力的一部分。
_Avoid_：模型已接入（不能据此推断该入口已提供全部能力）

**生成预设**：为某种创作目的提供的一组明确生成参数，例如用于快速探索的草稿配置。
_Avoid_：模型能力（预设是参数选择，不会增加模型可处理的范围）

**有效生成参数**：一次生成实际采用的参数取值，包括用户明确设置的值以及按规则补齐的值。
_Avoid_：用户填写的参数（用户填写的内容可能尚不完整）

**失败重试**：为完成原来的生成请求，在生成失败后沿用其有效生成参数，再作一次执行尝试。
_Avoid_：按当前默认再生成（原生成条件可能因此改变）

**新生成**：创作者主动发起的一次新的生成请求，可以使用与原生成相同或不同的条件；修改参数或采用新默认时属于新生成。
_Avoid_：失败重试（失败重试继续完成原来的生成请求）

**已提交任务的查询恢复**：创作环境中断后，继续查找原来已提交生成的进度和成果，不另发起一次生成。Q9 中的“任务恢复”专指此含义。
_Avoid_：失败重试（重试会再作一次生成尝试，可能产生新费用）

**排队任务续跑**：中断后，继续执行有可靠记录证明尚未提交、且原授权仍有效的待执行任务。它与查询已有供应商任务不同；结果未知不能被当成尚未提交。具体守卫见 [CJ-04](PRODUCT-JOURNEYS.md)。
_Avoid_：自动重试不明任务（不能据本地未完成就断言供应商未接收）

**结果待确认**：目前证据不足以确认一次生成仍在进行、已经成功或已经失败，需要继续查询或人工核实。
_Avoid_：生成失败（无法确认结果不等于已经失败）
