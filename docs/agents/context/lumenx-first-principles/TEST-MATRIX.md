公开整理：2026-10-30；来源快照 `7765f9e816088a88f8489a737ad70eb7211de051`。本页保留 44 个稳定功能编号，提供可在当前仓库打开的生产入口和代表性回归测试。它不是全部用例清单，也不宣布测试已经运行；收集清单、实际结果与未测范围见 [公开候选台账](EXECUTION-STATUS.md) 和 [发布准备记录](../../deliverables/github-release-2026-10-30/README.md)。原始逐片执行日志和增量记录留在研发分支。

## 证据层级

| 标记 | 实际验证对象 | 边界 |
|---|---|---|
| U | 生产函数、模型与状态规则 | 不在测试内复制业务实现 |
| I | 实际服务/adapter 与隔离依赖集成 | 外部传输替身不证明真实模型 |
| H | 应用 HTTP 请求/响应/错误/状态 | 应用导入和测试收集前必须隔离 |
| V | 实际组件、store、客户端交互 | mock API 不等于端到端 |
| E | 浏览器或正式桌面通过真实测试后端完成旅程 | 本地、远程、安装包、收费供应商分别记录 |

[24 组旅程](PRODUCT-JOURNEYS.md)覆盖重要贯通行为；F 行和文件数量不代表覆盖百分比或通过数。新增操作、未收集测试、skip、镜像测试与真正执行通过必须分别报告。

## 收集与运行

后端先由 `scripts/run_tests_isolated.py` 创建临时 HOME/数据根、限制环境和网络，再导入应用。默认测试目录之外的两份 shared-asset 测试显式列入：

```bash
python3 -S scripts/run_tests_isolated.py --python .venv/bin/python -- tests src/apps/comic_gen/test_shared_asset_pool.py src/apps/comic_gen/test_shared_asset_channels.py --collect-only -q
python3 -S scripts/run_tests_isolated.py --python .venv/bin/python -- tests src/apps/comic_gen/test_shared_asset_pool.py src/apps/comic_gen/test_shared_asset_channels.py -q
npm --prefix frontend run test
npm --prefix frontend run test:ui
npm --prefix frontend run typecheck
npm --prefix frontend run build
npm --prefix frontend run lint
python3 scripts/build_model_catalog.py
python3 scripts/validate_model_catalog.py
python3 scripts/check_workflow_parity.py
python3 docs/agents/tools/check_lumenx_refactor_docs.py
```

`.venv` 是已安装项目依赖的测试解释器示例，不使用个人应用数据。执行前按本分支 CI 核对 Python/Node 版本及 FFmpeg/ffprobe；完整命令、结果、退出码与跳过须记录，catalog 生成后核对 Git 无意外差异。原始 lint 失败、既有基线和无新增检查分别报告，不伪造退出成功。

架构边界由 `tests/test_core_dependency_boundaries.py` 与 `frontend/src/__tests__/product-boundaries.test.ts` 保护。浏览器工具在 `docs/agents/tools/`，它们既是运行夹具也有自身回归；工具测试通过不等于已完成真实浏览器旅程。发布前还需按实际源码与安装入口核验依赖可重建性和所声明的环境。
