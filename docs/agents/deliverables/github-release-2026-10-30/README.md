查看结果时，先核对 PR 的最新提交与检查所运行的提交相同，再查看实际日志、退出码、用例数量和跳过记录。PR 说明应明确本机补充验证的源码版本与范围；仅有绿色检查名称不足以证明所有部署或供应商能力。本文不预填或复制动态结果，以免后续源码变化后留下过期的“通过”声明。
