02

现状评估

ScriptProcessor.tsx 仍为纯 textarea，但已具备完整视频管线和两阶段实体提取。

已有优势

  • 两阶段实体提取（extractPreview → confirm）
  • 系列感知（ReconcileModal 跨集合并）
  • 完整视频管线（剧本→分镜→视频）
  • 两层保存（Zustand + blur 持久化）
  • 完整 REST API（可编程集成）

关键缺口

  • 格式引擎：无自动排版（P0）
  • 语法高亮：元素无区分（P0）
  • Fountain 解析：无结构识别（P0）
  • 格式导出：无 FDX/PDF（P1）
  • 内联 AI：无上下文续写（P1）
  • 协作：无实时多人（P3）
// 当前数据流
textarea → onChange: setScript + updateProject(Zustand)
         → onBlur: PUT /projects/{id}/text
         → 「提取实体」: POST /extract_preview → LLM
         → EntityConfirmModal → PUT /reparse
