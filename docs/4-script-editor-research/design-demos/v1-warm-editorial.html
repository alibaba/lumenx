02现状评估

ScriptProcessor.tsx 仍为纯 textarea，格式引擎/高亮/解析/导出/协作全部缺失。但已具备完整视频管线和两阶段实体提取等差异化能力。

已有优势

  • 两阶段实体提取（extractPreview → confirm）
  • 系列感知（ReconcileModal 跨集合并）
  • 完整视频管线（剧本→分镜→视频）
  • 两层保存（Zustand + blur 持久化）
  • 完整 REST API（可编程集成）

关键缺口

  • 格式引擎：无自动排版（P0）
  • 语法高亮：元素无区分（P0）
  • Fountain 解析：无结构识别（P0）
  • 格式导出：无 FDX/PDF/Fountain（P1）
  • 内联 AI：无上下文续写（P1）
  • 协作：无实时多人（P3）

07前端设计方向

从「空白 textarea」升级为「沉浸式创作座舱」——Block 编辑 + 三栏布局 + AI 气泡 + 场景情绪色带。

布局
三栏：大纲 | 编辑 | 属性
左侧场景卡片大纲可拖拽，中央 Block 编辑区，右侧属性/AI 面板。
字体
JetBrains Mono + Space Grotesk
编辑区等宽字体保证格式对齐，界面用 Space Grotesk 保持品牌一致。
色彩
深色主题 + 语义色带
延续 #050508 背景，场景/对白/动作各有独特色彩标识。
签名元素
左侧场景情绪色带
每个场景头左侧显示情绪色带，通过颜色直觉标识场景氛围。

08功能路线图

4 阶段递进：格式引擎→结构化+AI→协作→生态。每阶段可独立交付价值。

Phase 1：格式引擎
P0 · 4–6 周
  • 引入 Tiptap 替代 textarea
  • 实现 Fountain Block 类型
  • 中文场景头扩展（内景/外景）
  • 语法高亮 + 行号
  • 基础大纲导航面板
Phase 2：结构化 + AI
P1 · 6–8 周
  • 实体 DB 实时同步
  • Inline AI 续写/改写（DashScope Qwen）
  • / 命令面板
  • Fountain / FDX / PDF 导出
  • 统计面板（字数/页数/时长）
Phase 3：协作 + 高级
P2 · 8–12 周
  • Yjs 实时协作（WebSocket 传输）
  • 版本历史 + 变更追踪
  • AI as CRDT Peer
  • 分屏格式化预览
Phase 4：生态
P3 · 12+ 周
  • CJK 多语言排版切换
  • 短剧模板（竖屏分镜）
  • 插件系统
  • Final Draft 完整导入/导出
