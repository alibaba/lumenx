4 状态转移图

[PENDING] ──── click "Generate" ────→ [PROCESSING]
    │                                           │
    │                                 success ──┤──→ [COMPLETED] ── click star ──→ [STARRED]
    │                                           │                      │
    │                                   error ──┘──→ [FAILED]            │
    │                                                    │             │
    │                                       click retry ─┘──→ [PROCESSING]   │
    │                                                                    │
    └─────────────────────────────── click "Regenerate" ─────────────────────┘──→ [PROCESSING]

Unstar: [STARRED] ── click starred candidate ──→ [COMPLETED]
状态转移规则

单向限制：Starred 不可直接回到 Pending（需先 unstar 回 Completed，再点 Regenerate）。Processing 过程中 CTA disabled。Failed 只能 Retry 或修改 prompt 后重新 Generate。

6 交互行为详述

6.1 点击展开/收起

行为

点击 collapsed card 任意区域 → 展开为 expanded。点击 expanded header 区域 → 收起。点击 expanded body 内容区域不触发收起（允许选择文字 / 操作 candidates）。排他展开：同一时刻只有 1 个 ShotCard 处于 expanded；展开新卡时旧卡自动收起 (accordion mode)。

6.2 Candidates 选择 (Starring)

行为

在 expanded 态下，点击任意 candidate thumbnail → 该 candidate 获得 starred 样式 (金色 border + 角标)。卡片整体 status 变为 starred。单选：每个 shot 只能 star 1 个 candidate。点击已 starred 的 candidate → unstar，卡片回到 completed。

6.3 右键菜单 / 长按

行为

右键任意 ShotCard 弹出 context menu：Regenerate / Edit Prompt / Compare Takes (打开 CompareModal) / Copy Prompt / Delete Shot (danger, 需二次确认)。长按 (mobile/tablet) 等效右键。

6.4 拖拽排序

行为

Collapsed 态下可通过左侧 shot-num 区域拖拽重排序。拖拽中: opacity: 0.6 + scale(1.02) + box-shadow: 0 8px 24px rgba(0,0,0,0.4)。放置目标位置显示 2px primary 水平指示线。Expanded 态不可拖拽。

6.5 键盘导航

行为

Arrow Up/Down：在 shot 列表间移动焦点。Enter / Space：展开/收起。Tab：在展开态内，焦点进入 candidates → action buttons。Escape：收起展开态。1-4 数字键：在展开态直接 star 对应编号 candidate。

6.6 批量操作

行为

Cmd/Ctrl + Click：多选 shot cards (collapsed 态)。选中后顶部浮现批量操作栏："Generate All" / "Delete Selected" / "Export Selected"。选中卡片获得左侧 2px primary indicator + 浅 primary bg tint rgba(100,108,255,0.04)。
