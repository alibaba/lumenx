# Intent Brief: Website as Worldview Entrance, Not Corporate Landing Page

## 1. Explicit goal

- Build a studio website that does not look like a generic consulting firm, agency portfolio, or content media site.
- The website should explain the studio’s worldview and invite like-minded builders to explore its work.
- It should include clear entrances to newsletters, articles, podcast, events, and future products.

## 2. Hidden tension

- The real challenge is not information architecture; it is species recognition.
- If the first screen feels generic, the project fails even if the sitemap is correct.
- The site must balance atmosphere with repeat-visitor efficiency.

## 3. Agent judgment

- The website should be treated as a world entrance plus project-universe index.
- The navigation should be clear, but the experience should feel like entering a named vessel or living world, not browsing cards.

## 4. Executable translation

- [ ] Create a hero section that establishes atmosphere before explaining services.
- [ ] Keep top-level navigation visible for fast return access.
- [ ] Use project-type navigation rather than platform/channel navigation.
- [ ] Give the highest-weight recurring content product a brighter visual presence.
- [ ] Keep future software products visible as “under construction” rather than hiding them.

## 5. Feedback target

- Product brief: define the site as worldview entrance + project universe.
- Design system: avoid generic SaaS / agency aesthetics.
- Content model: separate recurring content, articles, podcast, events, and products.

## 6. Verification method

- A new visitor should remember the studio’s worldview within 30 seconds.
- The site should not be mistaken for a consulting template or media archive.
- Repeat visitors should reach key sections quickly.

## 7. What not to do

- Do not lead with a service matrix.
- Do not make platform channels the primary navigation.
- Do not hide future product ambition just because the product is still early.
