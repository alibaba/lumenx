# Product Note: Elicitation Skill as an Intent Compiler

Elicitation Skill is a small but important product primitive for human-agent collaboration.

Many AI workflows assume intent is already clear. In practice, strong human judgment often appears first as a vague sentence, taste reaction, discomfort, or metaphor. If an agent executes immediately, it often creates a plausible but average plan.

This skill inserts a deliberate pre-execution layer:

1. Name the type of ambiguity.
2. Ask a few sharp questions.
3. Preserve the human’s original insight.
4. Compile the conversation into an Intent Brief.
5. Route the result into a real system or product change.

The product value is not in producing a prettier document. The value is in changing what the agent does next.

## Core insight

The bottleneck in agentic work is often not execution speed. It is intent quality.

## Ideal use cases

- Product definition
- Agent behavior design
- Workflow redesign
- Creative direction
- Postmortem learning
- Taste alignment
- Strategic planning

## Anti-goals

- Long intake forms
- Generic consulting questionnaires
- Meeting summaries
- Premature PRDs
- Execution plans before the hidden judgment is clear
